## 2. 本阶段战略

### 2.1 四柱目标

| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **完局去冗余** | 尘埃落定不再「终局摘要念一遍、封面再念一遍」 | 结算条瘦身；传记只在书里读 |
| **跟手翻页** | 拖页角 / 滑动 / 点页缘，纸跟着走再落下 | `LifeBook` 拖拽翻页 + 页缘热区；保留按钮与键盘 |
| **对开书页** | 桌面像摊开的书：左偶右奇、中缝阴影 | 双栏 spread 布局；窄屏降级单页 |
| **抽书—揭开—合上** | 书架点封面有抽书感；进书先揭封面；末页可合书回架 | 过渡动效 + 封面开合状态机 |

### 2.2 设计原则

1. **一书一命，一屏一事**：同一信息只在一个主表面出现；结算负责「终了与行动」，书负责「一生」  
2. **隐喻统一**：大厅是书房，书架是层架，阅读器是摊开的书——控件尽量像书具，少像仪表盘  
3. **手优先于按钮**：触控/拖拽/页缘点击为第一路径；按钮条作辅助与可达性兜底  
4. **桌面像书，手机像册**：宽屏双页对开；窄屏单页全幅，但仍有翻页手感  
5. **动效服务触感**：翻页 350～550ms；`prefers-reduced-motion` 必降级；音效可关  

### 2.3 明确不做

| 不做 | 原因 |
|------|------|
| WebGL / 真布料物理翻页引擎 | 包体与移动端成本；CSS/Canvas 2.5D 足够 |
| 强制全站去掉按钮导航 | 无障碍与老年玩家需要兜底 |
| 账号云书签 / 多端同步 | 规格外 |
| 重做事件与配图资产 | 本版不碰内容骨 |
| 把局中 HUD 也改成书本 | 推演操控仍用现有 HUD；书感聚焦阅读与完局路径 |
| 删除 `EndingReport.summary` 字段 | 分享/短传仍需要；只改 **展示位置** |

## 4. 产品规格

### 4.0 完局布局 `ending`（去冗余 · P0）

**原则**：完局第一屏 = **终局条（薄）+ 摊开的书（厚）**；传记叙事只走书。

```
┌─────────────────────────────────────────┐
│ 尘埃落定                                 │
│ [死标一句 / 可选小图]  评分 · 主线精标    │  ← 终局条（矮）
│ 〔复制短传〕〔分享图〕〔再开〕〔书架〕…    │  ← 行动
│ （新成就条，若有）                        │
├─────────────────────────────────────────┤
│                                         │
│           LifeBook（主区域）              │  ← 封面已含短传/立绘
│           默认揭开或合着可点揭开           │
│                                         │
└─────────────────────────────────────────┘
```

| 区块 | 保留 | 删除 / 挪走 |
|------|------|-------------|
| 终局条 | 死标精标、死因短句、评分、主线一词；可选死标图（若封面不再放大结局图） | 立绘、`ending.summary` 大段、与封面重复的 who 大标题 |
| 行动行 | 复制短传、下载分享图、再开一局、我的人生、返回大厅 | 「翻书回顾」主按钮（默认即书，不必再点） |
| 次级检视 | 「卷轴」「属性」「武学名号」收进 **⋯ 更多** 或页脚次链 | 与翻书并列抢主 CTA |
| 书区域 | 默认展示 `LifeBook`；短传只在封面 | 结算条不再渲染 summary |

**默认路径**：进入 `ending` → 直接见书（`endingReadAsBook = true` 且终局条已瘦）→ 玩家翻书读完一生 → 行动区再开/归架。

**分享口径**：`formatShareText` / 分享图仍用完整 `summary`；仅 UI 不在结算条重复贴出。

### 4.1 阅读器状态机（实体书）

```
合着（封面朝外）
  └─ 揭开 → 摊开阅读（对开/单页）
        ├─ 跟手翻页 / 页缘 / 按钮 / 键盘
        ├─ 目录点击 → 瞬移到目标页（可短翻页过渡）
        └─ 合上 → 回书架（或结算 CTA）
```

| 状态 | UI | 交互 |
|------|-----|------|
| `closed` | 只见封面立绘 + 结局角标 | 点击/空格「揭开」 |
| `open` | 对开或单页 + 书脊/中缝 | 翻页主路径 |
| `closing` | 合书动画 | 结束后 `onBack` |

### 4.2 跟手翻页（P0）

| 输入 | 行为 |
|------|------|
| 拖右页左缘 / 页角向左 | 掀向下一页；松手过阈值则翻过，否则回弹 |
| 拖左页右缘 / 页角向右 | 掀向上一页 |
| 点击右侧 15% 页缘 | 下一页 |
| 点击左侧 15% 页缘 | 上一页 |
| 水平 swipe（触控） | 同翻页方向 |
| 按钮 / ← → / Home End | 保留；大跨页可用短动画或瞬跳 |

**动效规格**

- 跟手：页片跟随指针，带弯曲阴影（可用伪元素或轻量 canvas）  
- 落定：350～500ms ease-out；锁连点至动画结束  
- 减弱动效：交叉淡入，无拖拽弯曲  

### 4.3 对开书页（P0～P1）

```
┌────────────┬────────────┐
│  左页(偶)   │  右页(奇)   │
│  插图/正文  │  正文/插图  │
│     ▎中缝   │            │
└────────────┴────────────┘
```

| 规则 | 说明 |
|------|------|
| 断点 | `min-width: 900px`（可调）启用双页；以下单页 |
| 配对 | 封面单独一屏；其后左=偶数逻辑页、右=奇数；目录可占整开或左目录右空白 |
| 翻页 | 一次翻一张「物理页」（露出下一对开），或一次掀右页露出下一左页——选型见 §7 |
| 插图 | 高潮/死亡图优先占单侧整栏，避免对开被裁碎 |

### 4.4 书架与书房（P1）

| 项 | 规格 |
|----|------|
| 抽书 | 点击封面：书略弹出 → 放大过渡进阅读器 |
| 归架 | 合书后缩回格子 |
| 层架 | 可选：横条搁板 + 书脊厚度暗示（不改成游戏货架 UI） |
| 进度 | 存 `lastPageIndex`；再次打开从书签页或封面+「续读」 |
| 已读 | 读到封底或主动合书时写 `readAt`（修正「一点开就已读」） |

### 4.5 沉浸增强（P2）

| 项 | 规格 |
|----|------|
| 翻页音 | 短纸声，默认开、设置可关；减弱动效时默关 |
| 丝带书签 | 用户可「夹此页」；书架卡角显示丝带 |
| 局中 live | 跟读可不播 3D；切「自由翻阅」时用同一套 open 交互 |

## 7. 翻页与对开选型（B0 必选）

### 7.1 翻页实现

| 方案 | 优点 | 风险 | 建议 |
|------|------|------|------|
| **A. 自研 CSS 3D + pointer 跟手** | 无新依赖、可控纸色 | 页角弯曲难做真 | **默认首选** |
| B. 引入成熟轻量翻页（如 page-flip 类） | 开箱跟手 | 包体、皮肤难贴武侠纸色、无障碍 | 仅当 A 两周内达不到跟手阈值 |
| C. Canvas 扭曲网格 | 视觉最好 | 工程量大、无障碍差 | 不做 |

### 7.2 对开翻页语义

| 方案 | 说明 | 建议 |
|------|------|------|
| **α. 一次掀一张纸** | 右页翻过去，露出新右页；左页随后更新 | 更像实体书，**首选** |
| β. 一次换一整开 | 左右同时换成下一对 | 实现简单，书感弱 |

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 完局条过瘦导致「没结束感」 | 保留死标一句 + 评分 + 分享；书封面承担仪式感 |
| 玩家找不到卷轴/属性 | 「更多」菜单或页脚次链，不与主 CTA 抢位 |
| 移动端拖拽与滚动冲突 | 阅读器内水平手势优先翻页 |
| 对开打乱现有页码心智 | 页码显示「第 x–y 叶」或保留逻辑页并注明对开 |
| 目录瞬跳与跟手翻页抢戏 | 目录保持瞬跳或极短过渡 |
| 音效扰民 | 默认轻、可关；减弱动效默认关 |
| live 模式性能 | 推演中默认弱动画；静止阅读再用全套 |
