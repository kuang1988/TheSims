# 武侠人生模拟器 — 设计文档 v0.2

## 1. 产品定位

一款**重武侠背景**的**网页端**文字人生模拟游戏。玩家在「入世」前随机获得属性与天赋词条，随后模拟从出生到死亡的江湖一生。支持两种游玩模式：

- **全自动**：系统逐年推演，仅观看事件与结果，目标一局 **2–4 分钟**，适合快速重开、刷词条组合。
- **半自动**：关键节点由玩家抉择，日常事件仍可自动推进，目标一局 **8–15 分钟**，适合代入与策略。

核心体验：**开局抽卡的爽感 + 江湖一生的戏剧感 + 武学/称号成长的收集感 + 死亡结算的回味**。

**本期不做**：多周目轮回记忆（上一世不影响下一世）；各局独立。

---

## 2. 世界观与背景（重武侠）

### 2.1 时代气质

虚构宋元之际的乱世江湖：朝廷、门派、绿林、商帮、魔教并存。天下有「九大门派」「三大魔教」「散修隐士」与无数地方势力。武道分为：

| 层次 | 称谓 | 说明 |
|------|------|------|
| 凡人 | 俗人 / 练体 | 未入武道或仅会拳脚 |
| 三流 | 江湖客 | 能以武谋生 |
| 二流 | 好手 | 一郡扬名 |
| 一流 | 高手 | 一省扬名 |
| 绝顶 | 宗师 | 天下闻名 |
| 陆地神仙 | 大宗师 | 开宗立派、改写江湖格局 |

寿命与武道相关：凡人约 60–80；入武道后体质增强，宗师可逾百，陆地神仙或有异数。

### 2.2 人生主轴（叙事骨架）

每位角色的一生默认沿「出身 → 启蒙 → 入江湖 → 立业/拜师 → 恩怨情仇 → 巅峰或陨落 → 归宿」推进，具体路径由属性、词条与事件共同塑造，例如：

- 名门之后 → 门派嫡传 → 掌门之争 → 武林盟主 / 内斗身死
- 孤儿乞儿 → 奇遇秘籍 → 成名立万 → 仇家围剿 / 隐退山林
- 商贾之子 → 亦商亦侠 → 金刀镖局 → 富甲一方 / 破产亡命
- 魔教血脉 → 黑道崛起 → 正邪大战 → 称霸 / 伏诛

### 2.3 势力与关系网（简化模型）

运行时不必做完整势力战争模拟，用**标签 + 好感/仇恨值**即可：

- **势力**：门派、魔教、朝廷、商帮、绿林、散修……
- **人物关系**：师父、师兄弟、道侣、仇敌、贵人、徒弟
- **江湖声望**：正道声望 / 邪道威名 / 朝廷功名（可互斥或并存）

事件可读写这些关系，从而触发后续连锁事件（如「仇敌复仇」「师父传功」）。

## 3. 核心循环

```
入世前：随机出身 + 属性 + 天赋词条（可重开）
    ↓
选择模式：全自动 / 半自动
    ↓
按岁推进人生（每年 0~N 个事件）
    ↓
事件结算 → 改属性 / 关系 / 武学 / 称号 / 财富 / 气运 / 寿命
    ↓
死亡条件达成 → 结算报告（含武学列表与称号）→ 成就 → 再开一局
```

## 4. 游玩模式与时长目标

### 4.1 全自动模式（目标 2–4 分钟）

| 项 | 规则 |
|----|------|
| 推进 | 默认「一气呵成」+ 可调倍速；也可「逐年快览」 |
| 抉择 | 所有选项事件由权重自动选择（见 4.3） |
| 打断 | 仅死亡、特殊结局、玩家手动暂停 |
| 节奏手段 | 压缩日志展示、合并低重要度事件文案、跳过无选项日常的逐字动画 |
| 目标体验 | 刷词条、看高潮、晒结算与称号 |

### 4.2 半自动模式（目标 8–15 分钟）

| 项 | 规则 |
|----|------|
| 推进 | 默认自动过「纯叙述/无选项」事件 |
| 抉择 | 标记为 `needsChoice` 的事件暂停，等待玩家选择 |
| 可选增强 | 「仅重大抉择暂停」（按事件重要度 ≥ 阈值） |
| 节奏手段 | 保留完整事件文案；状态页可随时查看武学/称号 |
| 目标体验 | 关键路口亲自决定命运，细看武学与名号成长 |

### 4.3 自动抉择权重（全自动 / 半自动可选）

按当前角色倾向打分选最高分选项：

- **心性档位偏正** → 偏好侠义、助人、正道选项  
- **心性档位偏邪** → 偏好狠厉、夺宝、魔道选项  
- **福缘高** → 偏好冒险、奇遇  
- **根骨/悟性高** → 偏好苦修、闭关  
- **魅力高** → 偏好交际、联姻、收徒  

同分则随机。词条可覆盖倾向（如「嗜杀」强制提高杀戮选项权重）。

开局可记住玩家上次选择的模式，允许中途切换（半自动 ↔ 全自动），切换后立即按新规则处理后续事件。

### 4.4 时长约束（设计时遵守）

| 模式 | 目标时长 | 内容侧约束 |
|------|----------|------------|
| 全自动 | 2–4 分钟 | 低重要度事件可「摘要一行」带过；重大事件才展开；默认高倍速 |
| 半自动 | 8–15 分钟 | 抉择点密度适中（全程约 8–20 次暂停为宜，避免刷屏打断） |

## 5. 入世前：出身、属性、天赋

### 5.1 出身（Birth）

随机抽取，影响初始属性修正、起始地点、早期事件池。

示例出身池：

| 出身 | 倾向 | 备注 |
|------|------|------|
| 农户之子 | 体魄+，财富- | 易遇匪患、从军、拜师 |
| 商贾之家 | 财富+，魅力+ | 易入商帮、镖局 |
| 书香门第 | 悟性+，根骨- | 易入朝廷、儒侠 |
| 武馆家眷 | 根骨+，武学启蒙早 | 易早入江湖 |
| 名门之后 | 全面+，仇敌风险+ | 门派剧情权重高 |
| 魔教余孽 | 邪道事件+，正道敌意+ | 黑道线 |
| 孤儿弃婴 | 福缘波动大 | 奇遇/惨剧两端 |
| 皇亲远支 | 功名线+，政治风险+ | 朝廷线 |

### 5.2 基础属性（建议 0–100，开局约 20–80）

| 属性 | 含义 | 主要影响 |
|------|------|----------|
| 根骨 | 身体天赋 | 修炼速度、伤病抗性、武道上限 |
| 悟性 | 领悟力 | 学武、奇遇利用率、突破成功率 |
| 福缘 | 气运 | 好事/坏事权重、奇遇率 |
| 魅力 | 气质人缘 | 交际、收徒、联姻、门派评价 |
| 体魄 | 当前身体状态 | 伤病、寿命消耗、战斗存活 |
| 心性 | 正邪倾向（见 5.2.1） | 事件池、自动抉择、正邪结局、称号倾向 |
| 机缘 | 隐藏/半隐藏 | 影响「改命级」事件出现率（可由词条大幅改动） |

衍生资源（非开局主属性，运行时变化）：

- **财富**、**武力**（综合战力，受武学列表加成）、**声望（正/邪/官）**、**修为境界**、**寿命剩余**、**伤势**
- **已学武学列表**、**已获称号列表**（见第 6、7 章）

属性可在事件中增减，并有软上限（词条可突破）。

### 5.2.1 心性：数值 + 档位（双轨）

心性同时维护**连续数值**与**显示档位**，二者联动：

| 项 | 规则 |
|----|------|
| 数值 | `-100 ~ +100`，事件可增减（如行侠 +5，滥杀 -8） |
| 档位 | 由数值映射，用于 UI 展示、事件条件、自动抉择粗分 |

档位映射（可调）：

| 数值区间 | 档位 | UI 示意 |
|----------|------|---------|
| +61 ~ +100 | 至善 | 正道侠名向 |
| +21 ~ +60 | 偏正 | 多为义举 |
| -20 ~ +20 | 中庸 | 亦正亦邪 |
| -60 ~ -21 | 偏邪 | 手段狠厉 |
| -100 ~ -61 | 极恶 | 魔道威名向 |

设计用途拆分：

- **数值**：精细加减、阈值触发、成就统计（如「心性曾达 +90」）
- **档位**：事件 `conditions`（如「仅偏邪及以下可入魔教核心线」）、自动抉择大类、称号池过滤

跨档时打日志提示（如「心性滑落：偏正 → 中庸」），半自动下可更醒目。

### 5.3 天赋词条（Traits）

开局随机 2–4 条（稀有度：普通 / 稀有 / 史诗 / 传说）。词条分三类：

1. **被动修正**：恒定改属性或权重（如「天生神力：根骨+15，体魄+10」）  
2. **触发器**：满足条件时额外事件或效果（如「逢凶化吉：体魄&lt;20 时 30% 触发贵人相救」）  
3. **剧情锁**：解锁专属事件链（如「血海深仇：15–40 岁高权重仇敌线」）

示例词条（初版池，可后续扩）：

| 词条 | 稀有度 | 效果概要 |
|------|--------|----------|
| 天生神力 | 稀有 | 根骨+，幼年易「力大无穷」事件 |
| 过目不忘 | 稀有 | 悟性+，学武耗时减少 |
| 霉运缠身 | 普通 | 福缘-，坏事权重↑ |
| 福星高照 | 史诗 | 福缘+，好事与奇遇↑ |
| 剑骨天成 | 史诗 | 剑系武学成长↑，易遇剑冢 |
| 魔种 | 传说 | 邪功上手快，正道追杀事件↑ |
| 医仙转世 | 史诗 | 易学医术，可解致命伤事件 |
| 红颜薄命 | 稀有 | 魅力+，情缘线易悲剧 |
| 战神血脉 | 传说 | 战斗类事件存活率↑，寿元消耗↑ |
| 隐世高人转世 | 传说 | 幼年易遇隐士收徒 |

**重开规则（初版）**：无限重开；后续可加「锁定 1 条词条再随机」等成就解锁（非必须）。

## 6. 武学系统（需可视化）

武学是角色成长的核心可见资产之一，**必须在状态页以列表形式展示**，而非仅隐式体现在境界里。

### 6.1 武学条目结构

```text
MartialArt {
  id, name,           // 如「独孤九剑」「降龙十八掌」
  type: 内功|外功|剑法|刀法|拳掌|轻功|奇门|医术|其他,
  grade: 凡|下乘|中乘|上乘|绝学|神功,
  level: 1–10,        // 修炼层数/熟练度
  effects: { 武力?, 体魄?, 突破率?, 检定加成?, ... },
  source: 门派传授|奇遇|夺自仇敌|自创|……,
  tags: [正|邪|剑|……]
}
```

### 6.2 获取与成长

| 途径 | 说明 |
|------|------|
| 拜师/门派 | 入门后按年或事件学会基础功法，可升级 |
| 奇遇 | 秘籍、石壁、古墓等直接获得较高品阶武学 |
| 战斗/仇敌 | 战胜后有概率夺得残卷或完整武学 |
| 自创（稀有） | 高悟性 + 高境界事件解锁 |
| 走火/入魔 | 邪功快速提升，伴随心性恶化与风险事件 |

每年或相关事件可提升 `level`；品阶越高，对**武力**与相关检定加成越大。

### 6.3 与境界的关系

- **境界**表示整体修为层次（未入门 → … → 大宗师）  
- **武学列表**表示具体招式/内功构成  
- 突破境界可要求「至少拥有 X 品阶武学」或「某类武学 level ≥ N」  
- 武力计算公式需显式计入武学列表（便于玩家理解「学了什么所以变强」）

### 6.4 UI 可视化要求

人生中「状态 / 武学」页至少展示：

| 列/信息 | 说明 |
|---------|------|
| 名称 | 武学名 |
| 类型 | 剑法/内功等 |
| 品阶 | 凡～神功，可用色阶区分 |
| 层数 | level 或「初学/小成/大成/圆满」映射 |
| 来源 | 可选，增强叙事感 |
| 空态 | 未学任何武学时提示「尚不会武，只凭蛮力」 |

结算报告中复述**最终武学列表**（可只展前若干 +「等共 N 门」）。

全自动模式下不强制每次学武弹窗，写入日志一行即可；半自动学绝学/神功时可短暂停顿炫耀。

## 7. 称号系统（江湖名号）

称号是角色在江湖中的**外号/名号**，通过事件获得，类似「神雕大侠」「君子剑」「恶贯满盈」——强化身份认同与结算传播性。

### 7.1 称号结构

```text
Title {
  id, name,              // 显示名：君子剑、神雕大侠
  rarity: 普通|稀有|史诗|传说,
  type: 正道|邪道|中立|趣味|职司,  // 职司如「丐帮帮主」
  conditions: 获取条件摘要（数据用）,
  effects?: { 声望?, 魅力?, 事件权重?, ... },  // 可无效果，纯荣誉也成立
  exclusiveGroup?: string, // 互斥组：同组可替换或不可并存
  isPrimary?: bool         // 是否可作为「主称号」展示在姓名旁
}
```

### 7.2 获取方式

| 方式 | 示例 |
|------|------|
| 关键事件达成 | 多次行侠 → 「侠名远播」类；剑术成名战 → 「君子剑」 |
| 职位/身份 | 成为掌门 → 「某某掌门」；执掌魔教 → 「教主」类 |
| 特殊剧情链 | 养雕/情深/独居襄阳一类事件链 → 「神雕大侠」风格称号（原创名号，避免直接照搬版权名也可做同构：如「神雕义士」） |
| 恶行累积 | 屠城、滥杀 → 「杀人狂魔」「恶贯满盈」 |
| 反差/趣味 | 武功低却爱吹牛 → 「嘴强王者」类（可选，调剂） |

**原则**：称号应让玩家「一眼能讲故事」；优先绑定高重要度事件，避免无感自动刷号。

### 7.3 主称号与列表

- 角色可拥有**多个称号**，状态页以列表展示（获得年份 + 来源事件一句话）。  
- **主称号**显示在姓名旁：`杨过 · 神雕大侠`；玩家可在半自动下手动切换主称号；全自动按稀有度/正邪匹配自动选主称号。  
- 互斥组示例：「正道盟主」与「魔教教主」不可同时为主称号；获得对立称号时可触发事件或强制替换。

### 7.4 与其他系统联动

- **心性档位**：正道称号权重随至善/偏正提升；邪道称号随偏邪/极恶提升。  
- **武学**：可要求「剑类武学 ≥ 上乘」才可获剑相关称号。  
- **声望**：部分称号提供声望或解锁专属事件（如有「君子剑」后易遇「以剑会友」）。  
- **结算短传**：标题优先用主称号；无称号则用出身+境界。

### 7.5 示例称号池（初版可先做 15–25 个）

| 称号 | 倾向 | 获取方向（概要） |
|------|------|------------------|
| 少年英雄 | 正 | 青年前成名战胜利 |
| 君子剑 | 正 | 剑法出众 + 心性偏正以上 + 成名事件 |
| 女中豪杰 | 正 | 女性角色线 + 高声望（若做性别） |
| 慈悲医仙 | 正 | 医术武学 + 多次救人 |
| 丐帮帮主 | 职司 | 丐帮线顶点 |
| 武林盟主 | 正/职司 | 正道巅峰事件 |
| 魔教教主 | 邪/职司 | 魔教线顶点 |
| 恶贯满盈 | 邪 | 极恶 + 多次杀戮事件 |
| 一剑西来 | 中立 | 剑系绝学 + 高武力 |
| 隐世高人 | 中立 | 高境界 + 低声望 + 隐退事件 |
| 败走麦城 | 趣味 | 多次惨败仍存活（可选） |

> 正式文案避免无授权照搬他人作品专有名号；可用「神雕义士」「君子剑」等同构原创名。

### 7.6 UI 要求

- 人生中：姓名旁显示主称号；称号列表页可点开看来源。  
- 获得时：日志高亮「江湖流传，人称 —— **某某**」；半自动可短暂停顿。  
- 结算：列出全部称号，主称号最大字号。

## 8. 人生时间轴

### 8.1 推进单位

以**岁**为最小推进单位。每年：

1. 年龄 +1，自然衰老/修为影响体魄与寿命  
2. 按阶段抽取事件（见下）  
3. 结算持续性效果（闭关中、受伤恢复、仇敌倒计时、武学修炼进度等）  
4. 检查死亡与结局条件  

### 8.2 人生阶段与事件密度

| 阶段 | 年龄 | 事件倾向 | 每年事件数（建议） |
|------|------|----------|-------------------|
| 幼年 | 0–7 | 家庭、体弱、启蒙、灾祸 | 0–1 |
| 少年 | 8–15 | 拜师、读书、习武、离家 | 1–2 |
| 青年 | 16–30 | 闯荡、爱情、门派、成名、夺号 | 1–3 |
| 壮年 | 31–50 | 立业、仇敌、争霸、收徒、职司称号 | 1–2 |
| 晚年 | 51–死亡 | 传功、隐退、清算、寿终 | 0–2 |

武道越高，晚年可延长；低体魄/高伤势提高早夭权重。

全自动为压时长，可将幼年多数年份合并为「幼年往事」摘要（除非触发高重要度事件）。

### 8.3 境界与成长（简化）

修为境界影响事件池与战力：

`未入门 → 练气/练体 → 后天 → 先天 → 宗师 → 大宗师`

突破依赖：根骨、悟性、机缘事件、闭关、奇遇、武学品阶。半自动下「是否冒险突破」可为抉择点。

## 9. 事件系统

### 9.1 事件数据结构（设计级）

```text
Event {
  id, name, text,
  stage: [幼年|少年|青年|壮年|晚年],
  tags: [门派|奇遇|灾祸|情缘|仇敌|朝廷|商途|修炼|称号|武学...],
  conditions: 属性/心性档位或数值/词条/关系/境界/武学/称号/出身,
  weight: 基础权重,
  importance: 1–5,          // 半自动「仅重大抉择」用；全自动摘要阈值
  needsChoice: bool,
  choices: [{
    text,
    effects,               // 属性、武学、称号、关系、境界、flag…
    requirements?,
    tendencyTags?          // 侠义/贪婪/谨慎… 供自动抉择
  }],
  chain?: nextEventId | flag
}
```

效果类型需覆盖：`addMartialArt` / `upgradeMartialArt` / `grantTitle` / `setPrimaryTitle` 等。

### 9.2 事件分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 日常 | 轻量叙述 | 赶集、练剑、治病 |
| 好事 | 增益 | 奇遇秘籍、贵人提携、商途得意 |
| 坏事 | 减益 | 匪患、恶疾、背叛、栽赃 |
| 抉择 | 需选项 | 救或不救、入魔或拒、争夺掌门 |
| 武学 | 学得/提升/走火 | 石壁悟剑、师父传功 |
| 称号 | 成名/夺号/恶名 | 华山论剑扬名、血洗山寨 |
| 连锁 | 多年跨度 | 结仇 → 复仇 → 灭门/和解 |
| 结局前置 | 导向特殊死法/结局 | 正邪大战、飞升失败 |

### 9.3 抽取规则

每年从候选池中按权重抽取：

1. 过滤：阶段、条件、冷却、互斥 flag  
2. 权重修正：福缘、心性（数值与档位）、词条、声望、武学、称号、当前 flag  
3. 保底：连续 N 年无「高重要度」事件时提高重大事件权重（防平淡）  
4. 互斥：同年避免多个同类高压事件（可配置）  

### 9.4 事件内容方向（重武侠示例）

- **奇遇**：悬崖掉落获秘籍、古墓、剑冢、仙缘残卷  
- **门派**：拜师、被逐、内斗、大比、叛门  
- **情缘**：侠侣、师妹、联姻、情劫  
- **仇敌**：杀父仇人、夺妻之恨、门派世仇  
- **正邪**：剿魔、入魔、卧底、围剿  
- **朝廷**：科举（书香线）、从军、官匪勾结  
- **商途**：开镖局、赌坊、盐帮  
- **成名夺号**：擂台、论剑、侠名、恶名（产出称号）  
- **生死**：重伤濒死、毒药、走火入魔、天劫（高境界）  

文案语气：文言白话结合，短段落，适合手机一屏阅读。

## 10. 战斗与冲突（轻量化）

不做即时操作战斗，采用**检定结算**：

```text
成功率 ≈ f(武力, 根骨, 体魄, 武学加成, 词条, 对方强度, 福缘)
```

结果档：大胜 / 险胜 / 两败 / 惨败 / 逃出生天。  
效果：伤势、声望、结仇、夺宝、学得残卷、称号进度、死亡。

半自动中，高危险冲突应为 `needsChoice`（硬拼 / 智取 / 求和 / 逃跑）。

## 11. 死亡与结局

### 11.1 死亡条件

- 寿命耗尽（寿终正寝）  
- 体魄 ≤ 0 且无「濒死救赎」触发  
- 特定事件直接致死（斩首、灭门、走火入魔）  
- 特殊：坐化、飞升成功（算结局而非惨死）  

### 11.2 结局标签（可多标签）

寿终正寝、战死沙场、死于非命、门派殉道、魔教覆灭、江湖传说、隐世而终、朝廷赐死、情劫自尽、突破失败、飞升（稀有）……

### 11.3 结算报告

死亡后展示：

1. 标题行：`姓名 · 主称号`（无则仅姓名）  
2. 生平摘要（短传：出身、最高境界、关键事件 3–5 条、代表武学、主要称号）  
3. **最终武学列表**与**全部称号**  
4. 最终属性（含心性数值 + 档位）、关系网摘要  
5. 成就列表（首次达成高亮）  
6. 本局评分（可选：寿元、成就、戏剧性、武道、名号）  
7. 入口：再开一局 / 分享文案  

各局独立，**无轮回继承**。

## 12. 成就与解锁（初版可少做）

用于拉长重玩价值（仍单局内，不做跨世记忆）：

- 达成「陆地神仙」「魔教教主」「武林盟主」等解锁新词条/出身（账号级收集即可）  
- 收集称号/武学图鉴  
- 特定死法成就（如「被徒弟背叛而死」）  

初版可只做成就记录，不做复杂解锁也成立。

## 13. 界面信息架构（网页文字流）

### 13.1 主要界面

1. **入世前**：出身、属性（心性同时显示数值与档位）、词条；模式选择；重开 / 开始  
2. **人生中**：年龄、境界、主称号、关键资源条；事件日志流；半自动选项  
3. **状态页**：详细属性、**武学列表**、**称号列表**、关系、flag  
4. **结算**：短传 + 武学 + 称号 + 成就 + 再来一局  

### 13.2 全自动 UX（服务 2–4 分钟）

- 默认「一气呵成」高倍速；低 important 事件折叠为摘要  
- 学武 / 获称号用一行高亮插入，不强制暂停  
- 可随时暂停切手动或打开状态页  

### 13.3 半自动 UX（服务 8–15 分钟）

- 无选项事件自动滚入日志  
- 有选项时暂停；学绝学、获史诗以上称号可短暂停顿展示  
- 可选：「重大抉择才停」

## 15. 技术建议（网页优先）

| 项 | 建议 |
|----|------|
| 平台 | **仅网页**（桌面 + 移动浏览器）；暂不考虑微信小游戏 |
| 形态 | Web 文字流（React/Vue 皆可） |
| 数据 | 事件/词条/出身/武学/称号为 JSON 或 YAML，与逻辑分离 |
| 存档 | localStorage；后期再云存档 |
| 随机 | 可种子化（便于测试时长与事件分布） |
| 文案 | 数据驱动，避免写死在代码里 |

## 16. 设计原则（开发时遵守）

1. **重武侠不等于重系统**：叙事、武学名、称号优先，数值战从简。  
2. **每局要有记忆点**：至少 1 次高戏剧性事件，或印象深刻的武学/称号。  
3. **坏事要有戏，好事要有险**：纯加减数值的事件要少。  
4. **模式平等**：全自动不是残缺版；自动抉择要像「这个人会做的选择」。  
5. **时长诚实**：全自动压摘要与倍速；半自动控制抉择密度。  
6. **成长可见**：武学与称号必须可在状态页一目了然。  
7. **单局完整**：不做跨局轮回记忆，单局内故事自洽即可。

## 18. 一句话总结

玩家在网页上带着随机江湖天命入世，以全自动快刷或半自动抉择走过一生；心性用数值与档位双轨衡量，武学列表与江湖称号共同见证成名或落魄，死时留下一篇带名号的武侠短传——然后重新开局，互不继承。
