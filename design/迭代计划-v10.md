## 2. 本阶段战略

### 2.1 目标（内容为主）

| 目标 | 玩家体感 | 抓手 | 优先级 |
|------|----------|------|--------|
| **薄链可复述** | 走过镖局/师徒/市井的局，能讲出 2～3 句连贯情节 | 短链节拍表 + 旗标/关系读写 | **P0** |
| **+200 事件** | 多周目重复感下降；冷门出身也有戏 | 配额表 + census 硬门槛 ≥559 | **P0** |
| **词条有戏** | 点到天赋不只改面板，偶尔改命运路口 | `conditions.traits` / 倾向覆盖挂钩 | **P0** |
| 局中也是书 | 推演主舞台是书 | 收纳 HUD（辅线） | P1 |
| 晒场列传页 | 分享图一眼列传 | `shareCard` 重做（辅线） | P1 |

### 2.2 设计原则（内容）

1. **链优先于堆**：每条新事件默认归属一条短链节拍（起 / 承 / 转 / 合 / 余波）；禁止「换皮日常」凑数  
2. **旗标可读**：短链用 `flags` / `relations` / `chain` 串起来；玩家不必看代码也能在日志里感到「这是同一件事的后续」  
3. **薄池先吃饱和**：escort / master / force / 幼年 未达「可感知」前，不优先加厚已厚的 sect 主干彩蛋  
4. **重大抉择不空气**：`importance≥3` 且 `needsChoice` 必须改属性/关系/旗/武学/称号/财富/寿命之一（守 choice-audit）  
5. **阶段有头有尾**：补幼年启蒙与晚年余波，避免「青年事件墙」  
6. **宁改旧孤岛，勿只加新孤岛**：可为旧 `(none)` 事件补 `chain`/回调，计入「薄链工程」但不计入 +200 净增（净增只计新 id）  

### 2.3 明确不做

| 不做 | 原因 |
|------|------|
| 无链换皮灌水（同文案改名复制） | 虚高 census、稀释气质 |
| 新开完整「第九门派」主轴 | 成本高；本版补短链与支线 |
| 为 +200 放松 choice/death 门槛 | 质量回退不可接受 |
| 本版重做阅读器 chrome | Phase 15 已满；壳层仅辅线微调 |
| 账号云同步 / 书城化 | 规格外 |

### 3.1 总量与门槛（P0）

### 3.2 薄链节拍规格（P0）

每条目标短链至少具备可感知的 **四拍**（可多事件覆盖同一拍）：

| 拍 | 含义 | 例子（镖局） |
|----|------|--------------|
| **起** | 卷入 | 接镖、立契、入局 |
| **承** | 过程 | 赶路、眼线、内讧、交情 |
| **转** | 抉择/危机 | 劫镖、卖主、舍身护镖 |
| **合 / 余波** | 了结与后文 | 交镖、封刀、仇敌记名、晚年被寻 |

| 链 | 开工 | 本版目标体量（含新事件） | 最低验收 |
|----|------|--------------------------|----------|
| **escort** | 3 | **≥28** | 抽样 10 局至少 3 局走出「接镖→危机→了结」 |
| **master** | 3 | **≥28** | 拜师或收徒后 ≥1 次回调（传功/考验/送别/反噬） |
| **force** | 2 | **≥18** | 市井好勇有胜负与余波，非单次打架 |
| **幼年启蒙**（stage 幼年，可跨 chain） | 11 | 幼年相关 **≥28** | 开局 10 岁前不空洞 |
| **love 余波** | 15 | 链上 + 余波事件净增见配额 | 情缘后至少一拍（成/破/守）可触达 |
| **bandit / merchant 短链** | 8 / 12 | 见配额 | 各有「起承转合」最小集 |

### 3.3 +200 配额表（规划分配 · 可 ±10% 调剂）

> 原则：**≥70% 配额进入薄链/短链/特质挂钩**；≤30% 可给已有中厚链加「二拍三拍」或凡尘支线，禁止全部泼进 sect。

| 配额带 | 约略条数 | 主 chain / 标记 | 内容要点 |
|--------|----------|-----------------|----------|
| 镖局短链 | **30** | `escort` | 接镖、护镖、劫镖、私吞、交镖、余党寻仇 |
| 师徒短链 | **30** | `master` | 拜师/拒师、传功、门户之争、叛师、送别、徒弟反噬 |
| 力道·市井武 | **22** | `force` + 市井 tag | 擂台、打手、护院、争码头、收手 |
| 幼年·少年启蒙 | **22** | 多 chain / 幼年·少年 stage | 家训、逃学、初见江湖、童子劫 |
| 情缘余波 | **18** | `love` | 定情后危机、分离、重逢、道侣晚景 |
| 绿林短链 | **16** | `bandit` | 入伙、分赃、招安、火并、金盆 |
| 商途短链 | **16** | `merchant` | 压货、砸场、官商、义商、血本 |
| 凡尘支线拍 | **14** | `civic` | 本业中的人情劫与归宿前涟漪（不稀释主弧） |
| 特质挂钩包 | **20** | 各链 + `conditions.traits` | 覆盖 `attr-audit`「仅 mods」词条优先名单 |
| 散修·奇遇接旗 | **12** | wanderer / 奇遇 tag | 奇遇必须留下可回调旗，禁止纯无效奇遇 |
| **合计** | **200** | — | 调剂时薄池（镖局+师徒+力道）配额之和不得低于约 70 |

### 3.4 单条事件写作门禁（P0）

新增事件须自检：

| 检查 | 要求 |
|------|------|
| id | 新、稳定、可读前缀（如 `escort_road_ambush`） |
| chain | 薄链事件 **必填** chain；禁止再扩大无意义 `(none)` |
| 节拍 | 注释或文档标明属于某链的 起/承/转/合 |
| 选项 | 若 `needsChoice`：每选项有效果；重大抉择有效命运钩 |
| 文案 | 武侠口语、可进书页；避免现代梗与说明书腔 |
| 重复 | 与现有事件主题撞车时改为「后续拍」而非平行换皮 |

### 3.5 特质挂钩（P0）

| 项 | 规格 |
|----|------|
| 输入 | `npm run attr-audit` 列出缺少事件条件的词条 |
| 本版 | 优先名单中 **≥15** 个词条新增 ≥1 条 `conditions.traits` 事件，或明确写入自动抉择倾向并有日志可感 |
| 禁止 | 只改数值、 forever 无剧情出口 |

### 3.6 辅线规格（P1 · 不挡内容 DoD）

#### 局中推演壳

若排期不足：**允许本版只交付内容柱**，壳/晒书面记入 Phase 17；但 **+200 与薄链验收不可降级**。
