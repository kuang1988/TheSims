## 2. 本阶段战略

### 2.1 双柱目标

| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **死因合理性** | 「我是谁 → 怎么死」说得通；单一死法不再霸榜 | 规则表 + 审计断言 + 通路/权重修订 |
| **凡尘全生涯** | 士农工商 / 江湖客从 **入世选命到死亡结算** 都能复述 | 身份旗 + 分龄节拍队列（对标门派 entry→mid→finale，但是凡人版） |

### 2.2 士农工商：全生涯承诺（v7.1）

**目标形态**：一条凡尘主弧 = 一部完整小人书，而不是中年插播三件事。

```
入世（出身/立业意向）
  → 少年·启蒙或立业入口（约 14–22）
  → 青年·成型节拍（约 22–35）
  → 壮年·中劫 / 成败岔路（约 35–50）
  → 晚年·归宿与余韵（约 50+）
  → 死亡（职业向死法 / 寿终 / 病榻……与弧绑定）
```

| 要求 | 说明 |
|------|------|
| **可贯穿** | 未改投名门/魔教/匪途时，队列持续保底推进到归宿与死出口 |
| **可改投** | 中途入门派等主族 → 凡尘队停增；已发生的凡尘经历保留为「前半生」叙事，不抹账 |
| **死在弧上** | 终局死因优先吃本业烙印（劳伤/债局/致仕/工伤等），避免无故战死、无徒门人反噬 |
| **节拍密度** | 全生涯约 **5～8 个有后果节点**（含重大抉择），禁止灌水日常 |

普通江湖人士弧同样按全生涯设计（卖艺/保镖/游方），强度略低于四业正规身份，可与「散修」收束互通。

### 2.3 仍遵守

1. 连贯优先于体量——**每条新事件必须改 flag / 关系 / 财富 / 死法出口之一**  
2. 抉择必须改命运；禁止空气重大抉择  
3. 身份自洽（门派契约不回退）  
4. 凡尘弧 **不强制压过** 已入门派/魔教主族；未入名门时才抬凡尘权重与保底队列  

### 2.4 明确不做

| 不做 | 原因 |
|------|------|
| 把所有局改成凡人局 | 门派/魔教仍是核心卖点 |
| 为凡人弧新开完整战斗系统 | 战略禁止 |
| 轮回 / 云存档 | 规格外 |
| 为 KPI 堆无后果日常 | 否决 |
| 四业各写 30+ 空气事件 | 用全生涯节拍表，不堆体量 |

## 3. 问题诊断

### 3.1 死因规则（Phase 8 带病点）

| 现象 | 含义 |
|------|------|
| **「门人反噬」占比过高（曾 ~33%）** | 徒弟线过热，凡人局也被拖进「逆徒刀」 |
| 精标已拆、「死于非命」主标可控 | ✅ 保留 |
| `deathIdentityMismatch` 偏宽松 | **未校验「商贾/农户却战死沙场」类软违和** |
| 寿终类区间已达标 | ✅；凡尘全生涯应 **更多善终/病榻/劳伤** |
| 规则分散 | 缺「身份×死因」允许表，难与全生涯弧绑定 |

### 3.2 内容空洞：凡尘未贯穿

- 出身有农户/商贾/书香等，但 **缺少从入世排到死亡的保底队列**（门派有 `ensureSectStoryQueue`，凡人没有对等物）  
- 主线族几乎只有门派/魔教/匪/情/正道；`detectMainline` 无市井/商途/农桑/江湖客  
- 中晚年易被随机池与关系死法打断，**传记在「立业」处断更**  
- 普通江湖客缺少独立全生涯弧，易被吸进名门或空转

## 4. 验收指标

### 4.1 死因

| 指标 | 目标 | 测法 |
|------|------|------|
| 单一精死标霸榜 | 任一主死标 ≤28%（理想 ≤22%） | 扩展 `death-audit` |
| 门人反噬 | ≤18% | `death-audit` |
| 软身份违和 | `softMismatch` ≤20% | `death-audit` |
| 凡人弧善终 | 凡尘主线局：寿终+病榻+劳伤等本业死 ≥45% | 分桶审计 |
| 弧绑定死 | 走完凡尘归宿旗的局，死因与本业允许表匹配 ≥80% | 分桶 + 允许表 |
| Phase 8 旧门槛 | 死于非命≤25%；寿终类 15%～45%；精标≥8；硬 mismatch≤25% | 不回退 |

### 4.2 凡尘全生涯

| 指标 | 目标 | 测法 |
|------|------|------|
| 四业贯穿 | 士/农/工/商各具备 **入世意向→…→归宿→死出口** 全套节拍（缺龄段视为未完成） | 事件表 + `civicPath` 断言 |
| 江湖客贯穿 | ≥1 条同等全生涯弧 | 同上 |
| 保底触达 | 未入名门主族时，≥70% 局能播到「晚年归宿」拍；≥50% 死出口吃到本业烙印 | 批跑抽样 |
| 凡尘主线占比 | 批跑「凡尘主线」≥25%（未强制入门设定下） | 审计/抽测 |
| 可复述 | 结算能按时间说出「少时立业 / 中年一事 / 如何死」三句 | 人工 ≥8 局 |
| 空气 / 门派 | `choice-audit`=0；`sect-fork` 不回退 | 门禁 |

## 6. 分柱细则

### 6.1 死因合理性

**原则**：先能量化，再改规则；凡人桶与门派桶分看。

| 项 | 做法 |
|----|------|
| 允许表 | 战死需战场烙印；赐死需官身语境；门人反噬需徒弟烙印 |
| 弧绑定 | `civic_shi_finale` / `civic_nong_*` 等归宿旗 → 优先本业死法或寿终变体 |
| 降热 | 逆徒出口降权；无学生旗禁止门人反噬文案 |
| 审计 | Top 主标、分主线桶、softMismatch、弧绑定命中率 |

### 6.2 士农工商 · 普通江湖（全生涯节拍表）

**原则**：每业一条主链，分龄保底；与现有商途/朝廷事件接线复用，不堆空气。

| 弧 | 入世/启蒙 | 成型 | 中劫 | 归宿 | 死亡出口（示例） |
|----|-----------|------|------|------|------------------|
| **士** | 攻书 / 乡试意向 | 中举或落榜另途、坐馆 | 宦海或清流劫 | 致仕 / 罢官归乡 | 无疾致仕终 / 狱中或郁卒（慎赐死） |
| **农** | 守田 / 扛活 | 成家置地或逃荒 | 田讼、天灾、迁徙 | 守墓田或城中客居 | 劳伤田埂终 / 病榻 / 天年 |
| **工** | 学艺（可补工匠出身） | 出师、承造 | 夺艺、工变、开铺成败 | 传艺或关铺 | 工伤 / 艺成寿终 |
| **商** | 学徒跑街 / 父荫开号 | 立号、联姻商 | 商战、镖银、破家 | 富甲或收手 | 债逼而终 / 富室善终 |
| **江湖客** | 卖艺、短工、跟镖 | 一城薄名或栽面 | 卖命单、结仇或收徒 | 游方 / 开小馆 | 散修坐化风 / 仇敌（可选） |

**`ensureCivicStoryQueue`（对标门派）**

1. 入世：按出身 tags 或首择打上 `civic_shi|nong|gong|shang|wanderer` 意向  
2. 按年龄保底排队：entry → form → mid → late（各业事件 id 表驱动）  
3. `civic_*_finale` / 归宿旗落地后，挂死法相关余波或交给寿命/本业 `flavor*Death`  
4. 若玩家改投门派/魔教/匪：`clearCivicQueueGrowth`，保留已玩旗作回忆  

**与名门主族**

- 未入主族：凡尘权重抬升 + 队列保底（保证能活到归宿）  
- 已入主族：停增凡尘队；主线以门派等为准，凡尘经历仍可进短传「少时…」

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 全生涯变长篇注水 | 节拍上限 5～8；每拍改命运；禁纯日常 |
| 与门派抢戏 | 入籍停增；权重可测 |
| 四业内容量爆炸 | 每业一条主链 + 少量分支，复用旧事件接线 |
| 贯穿导致寿命玩不够 | 归宿后允许自然寿终；软延死与 Phase 8 余波策略对齐 |
| 死因表过严种类塌 | 先 soft 报告，再硬改写 |
