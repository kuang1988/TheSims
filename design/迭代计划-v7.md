## 2. 本阶段战略

### 2.1 三柱目标

| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **开场大厅** | 打开站点先见品牌与主行动，而不是直接扔进入世表单 | `home` 屏：开始游戏 / 我的人生 / 次要入口 |
| **人生书架** | 「我走过的每一生」像书架上的书，可扫可读 | `shelf`：3 列封面网格 + 书名 + 状态 |
| **仿真翻书** | 点开某本人生，纸页有透视/卷曲翻过的感觉 | CSS 3D / 轻量翻页库；键盘与按钮并存 |

### 2.2 设计原则

1. **一书一命，一架多生**：局内仍是一本；局外书架收藏已完结（及可选未完）传记  
2. **参考网文书架，气质仍武侠纸色**：网格与封面卡布局可参考上图，但禁用霓虹/都市小说风；封面优先用 **立绘 + 死标图/高潮图** 合成，不堆无关网文图  
3. **翻页要「像书」不要「像幻灯」**：有书脊遮挡、页角卷曲或硬翻 3D，时长约 350～550ms，可减弱动画  
4. **存档克制**：本地 `localStorage`（或 IndexedDB 若体积超限）；默认保留最近 N 本，可手动删除  
5. **开场不挡老玩家**：开始游戏 → 现有入世；我的人生 → 书架；图鉴/种子可作次级  

### 2.3 明确不做

| 不做 | 原因 |
|------|------|
| 账号云同步 / 多设备书架 | 规格外 |
| 商用网文封面爬取 | 版权与气质不符 |
| 真物理引擎布料仿真 | 成本高；CSS 3D / 成熟翻页方案足够 |
| 重写模拟器与事件池 | 本版不碰玩法骨 |

## 4. 产品规格

### 4.1 开场界面 `home`

```
┌─────────────────────────────────────┐
│  武侠人生模拟器（大标题 / 一句副文）   │
│  [立绘或书册氛围图，非仪表盘]          │
│                                     │
│  〔 开始游戏 〕  主 CTA               │
│  〔 我的人生 〕  进入书架              │
│  〔 图鉴 〕〔 种子房 〕  次级           │
│  版本 / 本地存档提示（小字）           │
└─────────────────────────────────────┘
```

- **开始游戏** → `birth`（现入世流不变）  
- **我的人生** → `shelf`  
- **图鉴 / 种子** → 可弹层或子屏（复用现有 Codex / 种子房）  
- 首次访问：`screen` 默认 `home`（打破直入 birth）

### 4.2 我的人生 `shelf`（参考书架图）

| 元素 | 规格 |
|------|------|
| 布局 | **3 列**响应式网格（窄屏 2 列）；竖向滚动 |
| 封面卡 | 圆角封面图（约 3:4）；可选角标「精华」（高评分/传说称号） |
| 书名 | 主称优先：`姓名` 或 `姓名 · 主称号`；过长两行截断 |
| 状态 | `未读` / `已读` / `刚落成`（本机打开过封底则为已读） |
| 副信息 | 一行灰字：享年 · 主线 · 死标精标（可选） |
| 空态 | 「书架尚空。去开始游戏，写就第一本。」+ 跳转入世 |
| 操作 | 点击封面 → 打开该书阅读器；长按/菜单可删除（P1） |

**封面合成（优先级）**

1. 终局死标图作底 + 立绘角标（与结算分享图同源思路）  
2. 若无死标：立绘铺满 + 纸纹遮罩  
3. 禁止外链无关插画

### 4.3 点开人生书 → 阅读器（参考书内封面图）

- 复用 / 升级 `LifeBook`：封面页展示立绘、姓名、出身、种子、提示「揭开这一生」  
- 页脚：上一页 / 页码 / 下一页  
- **仿真翻书**：见 §6.3  
- 从书架进入：只读，不启动模拟；可「再续前缘」类按钮回 `home`/`birth`（P1）  
- 从本局结算进入：仍可翻完封底后回书架（自动上架）

### 4.4 人生书存档模型

```ts
interface LifeBookRecord {
  id: string              // uuid
  createdAt: number
  seed: number
  readAt?: number         // 有则「已读」
  title: string           // 展示书名
  coverPortrait: string   // portraitLook + gender 可重建 URL
  deathTag: string
  deathReason: string
  mainline: string
  finalAge: number
  score: number
  ending: EndingReport    // 含 lifeLog；注意体积
  badge?: '精品' | null    // 评分/稀有称号门槛
}
```

- Key：`wuxia-life-sim-shelf-v1`  
- 上限：默认 **24** 本，超出淘汰最旧（可配置）  
- 若 `EndingReport` 过大：P1 改为 logs 压缩 / IndexedDB  

**上架时机**：`buildEnding` 成功进入结算时 `upsert` 一本。

## 5. 验收指标

| 指标 | 目标 | 测法 |
|------|------|------|
| 开场 | 冷启动进入 `home`；三按钮可达 | 人工 |
| 上架 | 完一局后书架 +1，刷新仍在 | 人工 + 单测 load/save |
| 书架 UI | 3 列网格；书名+状态可见；空态正确 | 对照参考图气质 |
| 打开书 | 点击封面进入阅读器封面页 | 人工 |
| 仿真翻页 | 至少「硬翻 3D」或「页角卷曲」一种；←→ 可用 | 人工桌面+窄屏 |
| 减弱动画 | 系统 `prefers-reduced-motion` 时降级为交叉淡入 | 人工 |
| 回归 | test / choice / death / sect / census | CI/本地 |
| 性能 | 书架 24 本首屏可交互；翻页不掉帧严重 | 人工 |

## 7. 仿真翻书方案（H3 选型）

| 方案 | 优点 | 风险 | 建议 |
|------|------|------|------|
| **A. 纯 CSS 3D**（双面页 + rotateY） | 无依赖、可控、贴合现纸色 | 要自己处理阴影与手势 | **MVP 首选** |
| B. 成熟库（如 page-flip） | 手感强、省时间 | bundle、样式难融武侠纸 | 备选；需主题适配 |
| C. Canvas 网格变形 | 最仿真 | 工作量大 | 不做 |

**MVP 行为**

- 下一页：右页掀起向左翻；上一页对称  
- 翻页中禁用连点（锁 400ms）  
- 全自动推演跟读：仍可用「书签跳转」弱动画，避免每条日志狂翻

## 8. 风险与回滚

| 风险 | 缓解 |
|------|------|
| `lifeLog` 撑爆 localStorage | 上限 24；超限裁剪旧书；P1 IndexedDB |
| 翻页晕动 / 无障碍 | `prefers-reduced-motion` 降级 |
| 开场增加一层点击 | CTA 明确；可记住「跳过开场」（P2） |
| 书架与本局书两套状态乱 | 明确：模拟中用临时书；完局才入库 |

回滚：`home`/`shelf` feature flag；关则默认 `birth`，翻页回 Phase 12 淡入。
