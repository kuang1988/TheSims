| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **终局合理（本版加重）** | 结算标签能说出具体怎么死，而非千篇一律「死于非命」 | **拆粗标**、体魄死出口、寿终通路、一致性审计 |
| **交互与样式** | 入世有仪式、局中好读、结算一眼懂、晒卡好看 | 信息架构、移动端底线、分享图层级、轻反馈 |

1. 连贯优先于体量——**改节拍与出口，不堆空气事件**  
2. 抉择必须改命运  
3. 身份自洽（沿用 Phase 6 契约）  
4. 禁止空气新上线  
5. UI：**信息架构与可读性**，不做整站换皮 / 新设计系统大迁移  

### 2.3 明确不做

| 不做 | 原因 |
|------|------|
| 新玩法系统（即时战斗、领地、小游戏） | 战略禁止 |
| 轮回数值 / 跨世记忆 | 规格外 |
| 音效 BGM / 云账号 / 排行榜 | 非本阶段 |
| 为 KPI 空气扩事件池 | 否决 |

## 3. 问题诊断（第一版体感）

### 3.0 【P0 首症】终局几乎都是「死于非命」

**玩家体感**：结算 / 图鉴 / 分享图上，结局标签经常只剩或总是带着「死于非命」，死得没名目。

**实机审计（2026-07-23，`npm run death-audit`，30 局）**

| 项 | 结果 | 说明 |
|----|------|------|
| 「寿元耗尽，寿终正寝」 | **0%** | 寿终通路几乎摸不到 |
| 文案种数 | 6 / 池 16 | 种类塌缩，多死法未触达 |
| Top 死因文案 | 战死 30% · **遭人暗算，死于非命 27%** · 体魄崩解 13% · 沉疴 13% · 背叛 10% · 赐死 7% | 几乎全是横死路径 |
| Phase 7「非三选一」指标 | 仍 ~97% 达标 | **被副标签（宗师/门派等）抬过线，掩盖主死标同质** |

**根因（代码层，`src/lib/deathTags.ts`）**

1. **标签折叠**：`deathEndingTags` 把毒 / 背叛 / 仇敌·暗算 / 伤·崩解 / 病 **一律 `push('死于非命')`**——文案不同，晒出去仍是同一个粗标。  
2. **体魄死默认桶**：`flavorBodyDeath` 大量落到「体魄崩解，伤重不治」或「遭人暗算，死于非命」，再经上条折成粗标。  
3. **寿终通路过窄**：批跑寿终 0% → 玩家几乎看不到「寿终正寝 / 隐世而终」等善终标签，横死叙事被放大。  
4. **旧审计失效**：Phase 7 只防「三选一纯粗标局」，**不统计「主死因标签 = 死于非命」的占比**，故第一版可带病过关。

**本版终局柱因此改写为三刀（顺序固定）**

1. **拆标**：一对一文案 → 精标（毒发 / 仇杀 / 暗算 / 伤重 / 病榻 / 背叛…），「死于非命」仅作真正无特征时的兜底。  
2. **通路**：抬高合理寿终 / 坐化触达；收紧无特征体魄死；让 16 种文案真正进分布。  
3. **贴身份**：再做死因↔主称/主线/年龄 mismatch（在分布健康之后）。

### 3.1 交互与样式

- 入世屏过密：属性 / 词条 / 模式 / 种子 / 图鉴同屏，像工具面板而非「入世」  
- 局中日志与抉择在窄屏易挤；反馈多为裸 tip，仪式感在全自动高速下几乎无感  
- 结算按钮墙：复制 / 分享 / 回顾 / 图鉴并列，**死因与「活成谁」不够主角位**  
- 分享图能晒但偏文字堆叠，截图独立可读性不足  

### 3.2 人生连贯

- 门派高潮多压缩在约 20–30 岁；**中晚年易回落到随机池**，余波偏薄  
- 关系回调多为一次性 flag，缺「再见 → 变故 → 终局」多拍  
- 结算高光取「末几条高重要日志」，不像传记目录  
- 队列过期静默丢弃 → 玩家曾触发的线可能无回响  

### 3.3 终局合理（其余）

- 主称 / 门派 / 仇敌在场与死因仍可能跳戏（在拆标与通路修好后专项治）  
- 青年软保命后骤死，削弱「故事写完了」的句号感  
- 图鉴 `CODEX` 仍以「死于非命」为收集项之一——拆标后需同步图鉴词表，避免旧粗标继续占进度

## 4. 验收指标（交付时对照）

| 指标 | 目标 | 测法 |
|------|------|------|
| **主死标「死于非命」占比** | **≤25%**（理想 ≤15%） | **扩展** `death-audit`：统计 `endingTags[0]` 或 `deathEndingTags` 主标 |
| **精死标种类** | 批跑触达精标 ≥8 种（毒发/仇杀/战死/病榻/赐死/殉道…） | `death-audit` 标签分布 |
| 寿终类通路 | 寿终文案合计 **15%～45%**（禁止再出现批跑 ≈0%） | `death-audit` 死因文案 |
| 死因文案种数 | 单次 30 局批跑 ≥8 种 | `death-audit` |
| Phase 7 旧指标 | 「非三选一」仍 ≥40%，但**不再单独作为终局合格证明** | 降级为辅助 |
| 死因一致性 | 主线·主称·年龄·门派 vs `deathReason` mismatch ≤25% | `death-audit`（Sprint A 后半） |
| 移动端可玩底线 | 窄屏（≤390）抉择不挡主日志；触控目标 ≥44px | 走查 |
| 结算首屏 | 3 秒内能答：「怎么死、活成谁、一句人事」 | 走查 |
| 分享图独立可读 | 不靠复制文本也能读出主称 / **精死因** / 主线 | 截图抽测 ≥10 局 |
| 终章后可复述 | ≥70% 局终章后仍有 ≥2 句后半生节拍 | 批跑 + 抽测 |
| 关系多拍 | 情缘 / 师徒 / 仇敌各 ≥2 拍入口 | 事件表 + 种子 |
| 高潮像目录 | 高光含链入口 / 中劫或终章 / 关系或余波（能采则采） | `buildEnding` |
| 回归 | sect-fork / choice-audit / test 不回退 | 门禁 |

## 6. 分柱细则

### 6.1 用户交互体验与样式

**原则**：同一视觉语言内做**层级与节奏**，不另起炉灶。

| 项 | 做法 | 不做 |
|----|------|------|
| 入世 | 主路径：抽命 → 确认入世；模式 / 种子 / 图鉴收入次级折叠 | 首屏再堆统计模块 |
| 局中 | 日志可读性、折叠低重要；半自动抉择固定触达区；toast 级反馈 | 大动效库、粒子特效 |
| 结算 | 视觉主角：**精死因** + 主称号；其次短传；再次人事 / 高光 | 按钮平铺；只晒粗标 |
| 分享图 | 主称 / **精死因** / 主线分层 | 再堆字段 |
| 移动端 | safe-area、触控高度、减死 `vh` 硬挤 | 独立 App 壳 |

### 6.2 模拟人生连贯性

**原则**：补**节拍**，不扩**无后果事件**。

| 项 | 做法 | 验收直觉 |
|----|------|----------|
| 第二幕 | 主族终章后挂「余波 → 归宿」短链（2～4 事件上限） | 「三十岁成名之后」说得出 |
| 关系弧 | 第二拍可接到**精死法**或人事 | 短传人事不是名单 |
| 高潮目录 | 从链入口 / 中劫 / 终章 / 回调采样 | 高光像目录 |
| 未竟之事 | 队列过期 → 低重要日志或结算一句 | 知道哪条线断了 |

### 6.3 终结合理性

**原则**：死是故事句号；**先有名目，再谈贴身份**。

| 项 | 做法 | 验收直觉 |
|----|------|----------|
| **拆粗标（先）** | 见 §5 A0 词表；审计盯主标占比 | 结算不再千人「非命」 |
| **通路（次）** | 寿终可触达；默认体魄死少用；16 文案进分布 | 批跑不再寿终 0%、种数过少 |
| 一致性（后） | 年龄 / 主称 / 正邪 / 仇敌 → 加权或否决 | mismatch 可下降 |
| 寿终分化 | 宗师坐化、隐士无疾、恶名旁落等 | 善终不雷同 |
| 图鉴 | 精标入库；旧「死于非命」降为稀有兜底项 | 收集有区分度 |

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 只改标签文案、分布仍全是横死 | A1 必须动寿终/体魄通路，门禁盯寿终区间 |
| 精标过多、结算像词云 | **主死标只取 1 个**；副标 ≤2（身份/门派） |
| 抬寿终过度 → 又变「清一色寿终」 | 寿终合计上限 45%；守种类 ≥8 |
| 补余波滑向空气事件 | 每条改 flag / 关系 / 死法出口；`choice-audit` |
| 与 Phase 6 契约冲突 | 余波尊重离派清旗与单焦点 |
| UI 越改越花 | 「3 秒三问」走查；禁止新主题色体系 |
