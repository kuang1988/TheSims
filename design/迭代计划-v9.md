## 2. 本阶段战略

### 2.1 四柱目标

| 目标 | 玩家体感（对标网文 App） | 抓手 |
|------|--------------------------|------|
| **布局不穿帮** | 合封面/书页无字压字、无条压图；长短书名都干净 | 封面结构重构 + 叠层审计 |
| **沉浸阅读区** | 正文为大字号、舒适行距；插图不抢字；页边留白够 | 阅读排版体系 + 主题肤色 |
| **阅读器壳层** | 点一下出顶栏/底栏，再点隐去；目录抽屉、进度条 | 网文式 HUD（自动隐藏） |
| **可读设置** | 字号 / 行距 / 背景（纸色·素白·夜读）本地记住 | `readerPrefs` + 设置面板 |

### 2.2 设计原则

1. **借网文交互，不借网文皮**：布局参考番茄/起点/微信读书式「点显栏、目录、设置」；视觉仍纸色水墨，禁用霓虹、粉紫渐变、都市 UI 组件堆砌  
2. **层叠有序**：图、角标、书名、CTA **分区排布**，禁止绝对定位条带压住文档流标题  
3. **正文第一**：默认隐藏工具噪声；封面/高潮插页可强调图，正文页以字为主  
4. **手机优先可读**：窄屏单栏沉浸；宽屏可保留对开，但阅读设置与壳层统一  
5. **设置本地化**：字号等写入 `localStorage`，换局仍生效  
6. **无障碍兜底**：减弱动效时栏不自动藏死；字号下限可读  

### 2.3 明确不做

| 不做 | 原因 |
|------|------|
| 接入正版网文书城 / 外链小说 | 产品边界外 |
| 竖排繁体古籍排版引擎 | 成本高；本版横排优化即可 |
| 重做 3D 翻页物理 | Phase 14 已有；本版可不强调硬翻，可提供「滑动翻页」阅读模式 |
| 广告、充值、书架商城化 | 气质与规格不符 |
| 把局中推演 HUD 改成阅读器 | 仅优化 `LifeBook` 阅读路径 |

## 3. 问题诊断（Phase 14 阅读体感）

| 现象 | 对标网文 App / 可读性的差距 |
|------|------------------------------|
| **合封面字叠字（已复现）** | `.life-book__closed-badge` 绝对定位 `bottom: 3.2rem` 压在图底，与下方文档流书名（如「董承安」）重叠发糊；长角标更易穿帮 |
| 书架卡结局条 vs 书名 | 同构风险：图上 overlay 与卡下标题间距不足时也会挤 |
| 打开封面 `book-cover` 信息块 | 立绘角标 + 结局行 + who + summary 垂直堆叠，窄屏易挤、易与插图抢位 |
| 底栏按钮过多常驻 | 成熟阅读器底栏可点空白隐去 |
| 页眉偏文档 | 应像「章名 / 进度 %」 |
| 字号偏小、无主题 | 缺字号/行距/三肤 |
| 目录只在书内页 | 网文多为抽屉目录 |

### 3.1 文字重叠根因（合封面）

```
┌──────────────┐
│   立绘        │
│   ▓▓▓ 角标   │  ← position:absolute; bottom: 3.2rem（叠在图上）
│ ──────────── │
│ 书名（被压）  │  ← 文档流，与角标垂直抢同一带
│ 揭开这一生    │
└──────────────┘
```

**改造方向（规格）**

| 方案 | 说明 | 建议 |
|------|------|------|
| **A. 图文分区** | 图区只放立绘；角标改到图下信息区（书名上方一行灰字） | **首选** |
| B. 角标留在图内 | 仅允许图内底部渐变条；书名整体下移，用 `padding-top`/`min-height` 为角标让位 | 备选 |
| C. 角标改图内纯图标 | 不写长文案，文案全在图下 | 可与 A 合并 |

验收：任意书名（2～8 字）、任意死标文案，合封面 **无像素级叠字**；窄屏/桌面各测一局。

## 4. 产品规格

### 4.0 布局防重叠规范（P0）

| 规则 | 要求 |
|------|------|
| 禁止 | 绝对定位文案与文档流标题共用同一垂直带且无明确避让 |
| 合封面 | 立绘 / 元信息 / CTA 三区清晰；元信息含死标一行 + 书名 +「揭开」 |
| 书架卡 | 图上结局条不延伸出封面底边外压住书名；书名区独立 padding |
| 打开封面 | 角标仅在立绘框内；其下 summary 可滚动或限行，不顶飞 CTA |
| 高潮正文 | 插图与标题、段落间距 ≥ 0.5rem；不 `position` 压字 |
| 回归抽检 | 完局合封面、书架首卡、打开封面、死亡高潮页 四态截图无叠字 |

### 4.1 阅读器信息架构（网文壳）

```
┌──────────────────────────────────┐
│ 〔返回〕  章题/页题      〔目录〕 │  ← 顶栏（点显）
├──────────────────────────────────┤
│                                  │
│         正文阅读区（主）           │
│         （可含插图）               │
│                                  │
├──────────────────────────────────┤
│ 〔设置〕 ════●══ 42%  〔书签〕   │  ← 底栏（点显）
└──────────────────────────────────┘
```

| 区域 | 行为 |
|------|------|
| 点阅读区中部 | 切换顶/底栏显隐 |
| 点左/右缘 或 滑 | 翻页（沿用 Phase 14） |
| 目录 | 抽屉列出高潮目录（复用现 TOC 数据），点跳转后收起 |
| 设置 | 字号 −/＋、行距、主题肤、翻页动画开/关、纸声 |
| 进度 | 条显示阅读百分比；可选拖动改页（P1） |

### 4.2 排版规格

| 项 | 默认 | 可调范围 |
|----|------|----------|
| 正文字号 | 18px（窄屏）/ 19px（宽屏） | 15～24px |
| 行高 | 1.85 | 1.6～2.1 |
| 段距 | 0.65em | 随行高 |
| 页边距 | 左右 ≥1.1rem；上略紧 | 紧 / 标准 / 疏 |
| 标题 | 显示字族；正文可用阅读专用字重 | — |
| 插图 | 正文页 max-height 受限；死亡/高潮可略大 | — |

### 4.3 主题肤（三档）

| 肤 | 背景 | 字色 | 用途 |
|----|------|------|------|
| **宣纸**（默认） | 现有 paper 暖色 | ink | 武侠默认 |
| **素卷** | 近白浅灰 | 深灰 | 高对比日间 |
| **夜读** | 深墨底 | 浅米字 | 低刺激夜间 |

切换即时生效，写入 prefs。

### 4.4 页面类型样式分工

| 页类 | 网文式处理 |
|------|------------|
| **合封面（closed）** | 图文分区：立绘干净；死标+书名+「揭开」在图下信息带，**禁止角标压书名** |
| 打开封面 | 保留仪式感立绘；角标不出立绘框；summary 限高或可滚 |
| 目录页（书内） | 可降级为「首次引导」；主路径改抽屉目录 |
| 正文 spread | 干净：章题 + 正文；少装饰线 |
| 高潮/死亡 | 插图 + 短文；图下正文仍服从阅读字号；图文间距固定 |
| 封底 | 终局图 + 精炼句；分享入口可收底栏「分享」 |

### 4.5 与实体书能力的关系

| Phase 14 能力 | Phase 15 策略 |
|---------------|---------------|
| 3D 硬翻 / 对开 | **设置可关**；默认窄屏「滑动翻页」更像网文；宽屏对开可选保留 |
| 合着揭开 | 保留；揭开后进入沉浸阅读壳 |
| 续读 / 书签 | 保留；底栏书签与进度条对齐网文习惯 |
| 纸声 | 放进设置，默认关或沿用 prefs |

## 5. 验收指标

| 指标 | 目标 | 测法 |
|------|------|------|
| **无叠字** | 合封面 / 书架卡 / 打开封面 / 死亡页四处无文字重叠 | 人工对照截图（含长书名） |
| 沉浸 | 打开书后默认顶底栏隐藏或 2s 后隐；点中可唤出 | 人工 |
| 设置 | 字号/行距/三肤本地持久；刷新仍在 | 人工 + 单测 prefs |
| 目录抽屉 | 任意正文页可开目录并跳转 | 人工 |
| 排版 | 默认字号下手机可读一屏 ≥12 行等效舒适度 | 人工窄屏 |
| 主题 | 夜读对比清晰；宣纸仍武侠 | 人工 |
| 不回退 | Phase 14 续读/翻页手势仍可用 | 回归 |
| 审计 | test / choice / death / sect / census | CI/本地 |

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 合封面再叠字 | R0.5 强制图文分区；验收列入 DoD 首条 |
| 网文化后丢失武侠书感 | 默认肤仍宣纸；封面/揭开仪式保留 |
| 顶底栏与页缘翻页冲突 | 中带显隐；左右 15% 仍翻页；栏显时热区下移 |
| 对开 + 大字号溢出 | 大字号时自动关对开或单页优先 |
| prefs 与书声 prefs 分裂 | 合并进 `readerPrefs` 或明确双 key 文档化 |
