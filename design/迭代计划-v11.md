## 3. 本阶段战略

### 3.1 四柱目标

| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **数据可信** | 图鉴里看见的功法/名号，真有机会到手 | 接通死货 + data-audit |
| **身份可辨** | 当上武当掌门就是「武当真人」，不是糊成「一代掌门」 | 职司对齐 + 路径旗收敛 |
| **人设可扩** | 新特质/新武学/新称号有故事，不是数值贴片 | 扩表门禁 + 事件出口 |
| **图文同步** | 新高潮/新身份需要图时，清单与 webp 齐套 | 文生图附录 + manifest |

### 3.2 设计原则

1. **接通 ≥ 堆新**：未发放表项清到门槛前，限制纯炫技新 id  
2. **一门一途、一号一职**：武学/职司称号必须有 ≥1 稳定发放出口  
3. **命名空间隔离**：新特质/称号 **禁止** 再与另一实体共用裸 id；存量碰撞列入重命名或别名表（可分两步）  
4. **先清单后出图**：沿用 v5；无 `assetManifest` 键不入库  
5. **事件预算服务于表**：本版建议事件净增 **+60～100**（接通 + 新设计落地），不追求再 +200  

### 3.3 明确不做

| 不做 | 原因 |
|------|------|
| 再灌 +200 无链日常 | 稀释；Phase 16 已完成量目标 |
| 实时文生图 API | 规格外；静态资产 |
| 每个称号一张立绘 | v5 已否；称号用角标/文案 |
| 强制身份变脸 | 破坏出生锁定契约；最多「换装提示」 |
| 大改死因公式 / 离派拼盘 | 除非审计回退 |

## 4. 新增设计规格

### 4.1 武学（`martialArts.ts`）

| 项 | 规格 |
|----|------|
| 接通 | **16** 门未发放武学全部挂上事件出口（门派课表 / 奇遇 / 朝廷 / 邪功） |
| 新增 | **+8～12** 门（建议主题：镖护、市井外功、师门心法余绪、凡尘强身） |
| 门禁 | 新 id 合入 PR 必须含 ≥1 `addMartialArt`；上乘及以上建议有升级或代价旗 |
| 禁止 | 只进表、只出现在图鉴 |

| 门派/路径 | 应发放（含接通） |

### 4.2 身份（出身 · 路径 · 职司）

| 层 | 规格 |
|----|------|
| 出身 | **+0～3**（慎重）；优先给现有 farmer/orphan/artisan/wuguan 各 **1～2** 幼年专属事件 |
| 路径旗 | 收敛命名：`path_sect_*` / `path_court` / `path_merchant` / `path_escort` / `path_bandit`…；旧旗可作别名兼容一版 |
| 职司称号 | 华山/武当/少林/峨眉/丐帮终章 → 对应细分职司（或 `zhangmen` 降权为兜底） |
| 朝廷 | `qincha` / `chaoting_gong` 至少各 1 稳定出口 |
| UX | 身份变化时 HUD/书页元信息可读；立绘不强制换 |

### 4.3 称号（`titles.ts`）

| 项 | 规格 |
|----|------|
| 接通 | never-granted 清单 **清掉 ≥70%**（优先职司/传说/史诗） |
| 新增 | **+6～10**（填空白：镖门名号、市井力士、师门「传人」类；少趣味灌水） |
| 发放治理 | 降低对 `yinshi`/`duxing`/`xiake` 的滥发；终章优先 `exclusiveGroup` 互斥兑现 |
| 命名 | 新称号 id 加前缀或避免与 `traits` 撞车（如 `title_yinshi` 仅作迁移目标，本版可先禁新碰撞） |

### 4.4 特质（`traits.ts`）

| 项 | 规格 |
|----|------|
| 债 | `shenli` / `yinshi` 等补 **专属短链或强化 drive** |
| 新增 | **+8～12**（建议主题：**镖骨**、**匠心**、**市井力**、**师门根**、**漕帮气**、**读书种子**…） |
| 门禁 | 稀有+：≥1 `conditions.traits` 或 trait-drive 事件；禁止纯数值传说 |
| Synergy | 新特质至少评估 1 条联动；本版 synergy **+2～4** 可选 |
| 描述 | 短描述需含「命运钩暗示」（会改抉择/事件），禁止空口号 |

## 5. 文生图同步规划

### 5.1 原则（继承 v5）

1. **先冻结附录清单，后出图**  
2. 命名：  
   - `portrait/p_{m\|f}_{archetype}.webp`  
   - `climax/c_{chain}_{beat}.webp`  
   - `ending/e_death_{fineKey}.webp`  
   - 可选 `ending/e_finale_{eventId}.webp`  
3. 新事件优先 **映射现有高潮桶**；仅新主题链才开新文件  
4. 称号/多数特质 **不出立绘**；气质写进提示词或角标  

### 5.2 本版建议出图范围（P0～P1）

| 优先级 | 资产 | 数量（约） | 触发条件 |
|--------|------|------------|----------|
| **P0** | 薄链高潮桶 | **6** | `c_escort_mid` / `c_escort_finale`、`c_master_mid` / `c_master_finale`、`c_force_mid` / `c_force_finale` |
| **P1** | 立绘矩阵补洞 | **0～2** | 仅当明确要做女少林或男峨眉独立气质；否则保持回落并写清 |
| **P1** | 新死标 | **按条** | 仅当新增 fineKey；同步 `DEATH_TAG_FINE_KEY` |
| **P2** | 门派 finale 精绘 | 可选 | 不阻塞 DoD |
| — | 新称号卡 | **0** | 不做 |

### 5.3 同步流程（硬）

```
设计冻结（武学/称号/特质/身份出口 id）
    ↓
附录 A/B 文生图清单评审
    ↓
改 assetManifest（键先于图）
    ↓
出图 → public/assets/**（webp）
    ↓
assetResolve 单测 + 人工抽检无图回落
    ↓
事件发放与配图绑定合入同一里程碑
```

### 5.4 提示词气质（与产品一致）

- 宋元乱世 · 水墨纸色 · 忌霓虹与现代物件  
- 立绘：半身/三分身、可识别门派或市井身份符号  
- 高潮：情节瞬间，少群像人脸特写堆砌  
- 与分享列传页、书内插图同一套色温
