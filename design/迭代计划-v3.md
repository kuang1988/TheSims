## 2. 本阶段战略

### 2.1 三角目标

| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **页面样式** | 入世 / 局中 / 结算三屏像同一本书的不同页，而非表单堆叠 | 间距节奏、纸面纹理、状态色、组件统一 |
| **文字渲染** | 长文好读、高潮好认、中文不「糊 / 挤 / 跳」 | 字号阶梯、行高/字距、落款字体职责、抗锯齿与换行 |
| **整体交互** | 点哪里心里有数；等待有反馈；窄屏不打架 | 焦点态、触控、toast、滚动与抉择区、动效克制 |

### 2.2 设计原则

1. **一书一气**：保留现有纸色 / 朱砂 / 金线气质，只做层级与节奏，不另开赛博风  
2. **读优先于饰**：任何装饰不得压过日志正文与抉择文案  
3. **少而准的动效**：进入、高潮、仪式各保留有意的 1～2 处；禁止无意义闪烁  
4. **触控与键盘同等**：按钮 ≥44px、可见 focus、半自动抉择永远可点到

## 3. 问题诊断（第二版体感）

### 3.1 页面样式

- Token 已有（`--ink / --paper / --cinnabar`），但 **组件间距与圆角语言不统一**（有的硬边、有的挤）  
- 入世「展开详细」后仍偏工具感；局中 HUD / 日志 / 抉择 **三块视觉权重接近**  
- 结算精死因已突出，但标签胶囊、按钮组、次级折叠的 **呼吸感不足**  
- 背景噪点 + 深底对纸面对比够，小屏上顶栏与主栏衔接略跳  

### 3.2 文字渲染

- 正文字体 `Noto Serif SC` + 标题 `ZCOOL XiaoWei` 分工正确，但：  
  - **字重阶梯弱**（400/600/700 未系统用在日志 importance）  
  - 长日志行长偏满，移动端 **换行切词生硬**（无 `line-break` / 段落节奏）  
  - 高潮日志与日常日志 **字色区分主要靠标题色**，正文仍易糊成一片  
  - Google Fonts 依赖外网；弱网时 **FOUT / 回退宋体** 观感差  
- `index.css` 几乎空壳，排版规则散落在 `App.css`，难统一维护  

### 3.3 整体交互

- 反馈仍偏 `copyTip` / `ritualTip` 裸文本，**缺统一 toast / 短驻反馈层**  
- 全自动高速刷日志时，用户难感知「刚发生了大事」（仪式条在 auto 下弱）  
- 半自动抉择区虽 sticky，但与「继续推演」按钮 **语义仍易混**  
- 焦点态（`:focus-visible`）与禁用态未系统化；键盘用户体验弱  
- 入世 CTA 主次已调，但种子房 / 图鉴展开时 **页内跳动** 仍大

## 4. 验收指标

| 指标 | 目标 | 测法 |
|------|------|------|
| 三屏视觉同书 | 入世 / 局中 / 结算共享同一间距尺度与标题阶梯 | 设计走查清单 |
| 正文可读 | 日志正文字号 ≥16px（桌面）、行高 1.7～1.85；行宽舒适 | 桌面 + 390 宽走查 |
| 高潮可辨 | importance≥4 日志在 1 秒内可从流中认出 | 抽测 5 局 |
| 字体稳定 | 关键屏在弱网/缓存下不出现明显「字体跳变」超过 1 次 | 限速复现 |
| 触控底线 | 主按钮 / 抉择 ≥44px；抉择不挡日志阅读终点 | 窄屏走查 |
| 反馈统一 | 复制 / 分享 / 仪式 / 错误 均走同一反馈组件 | 代码走查 |
| 动效克制 | 新增动效 ≤3 类；无无限循环装饰动画 | 走查 |
| 回归 | test / death-audit / choice-audit / sect-fork 不回退 | 门禁 |
| 构建 | `npm run build` 更新 `docs/` | 发布 |

## 6. 分柱细则

### 6.1 页面样式

| 项 | 做法 | 不做 |
|----|------|------|
| Token | 补 `--radius-sm/md`、`--space-1…6`、`--text-xs…xl` | 换紫色科技风 / 大圆角卡片墙 |
| 入世 | 主路径留白；次级折叠视觉降噪 | 再堆统计模块进首屏 |
| 局中 | HUD 紧凑条；日志为视觉主角 | Dashboard 多栏信息过载 |
| 结算 | 维持精死因主角；标签/按钮组垂直节奏 | 恢复按钮墙 |
| 纸面 | 微调边线与内阴影，增强「书页」 | 重噪点、强发光 |

### 6.2 文字渲染

| 项 | 做法 | 不做 |
|----|------|------|
| 字体职责 | XiaoWei = 品名/标题/死因；Noto Serif = 正文/日志；等宽仅种子数字 | 三屏混用无规则 |
| 阶梯 | h1 / eyebrow / lead / log / meta 固定 scale | 随手写 `font-size: 0.92rem` 散落 |
| 中文 | `line-height` 1.75 上下；段落间距；避免字距过大导致「散」 | 英文 kerning 思维硬套 |
| 高潮 | imp-4/5：标题加粗 + 左边线/底色淡染；正文略提对比 | 整段闪红 |
| 加载 | 预连接 + 关键字重；考虑本地子集兜底 | 一次拉全字重拖慢首屏 |

### 6.3 整体交互

| 项 | 做法 | 不做 |
|----|------|------|
| Toast | 单槽反馈：成功/提示/失败，2s 自动消 | 多条堆叠弹幕 |
| 抉择 | 文案区与按钮区分明；主操作「继续推演」唯一 primary | 两个同等 primary 抢戏 |
| 焦点 | `:focus-visible` 描边；禁用降透明且不可点 | 去掉 outline 且无替代 |
| 滚动 | 新日志进入时温和跟随；用户上翻时暂停强制 scroll（可选） | 永远抢滚动 |
| 动效 | rise / ritual / toast-in 三类上限 | 背景无限粒子 |
