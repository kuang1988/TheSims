## 2. 本阶段战略

### 2.1 三柱目标

| 目标 | 玩家体感 | 抓手 |
|------|----------|------|
| **家底可见** | 知道系统有多少事件、哪条链厚/哪条薄 | `event-census` 脚本 + 附录基线表 |
| **日子更像人生** | 除门派决战外，多邻里、钱粮、人情、节气琐事 | **净增 ≥50** 条 `EventDef`（见 §6） |
| **一生一书** | 开局是封面，岁月是书页，结算是封底；可翻页通读 | Book UI：封面 / 正文页 / 高潮插页 / 封底 |

### 2.2 设计原则

1. **一书一命**：每局人生 = 一本书；重开天命 = 换一本新书，不混页  
2. **翻页优先于长滚**：默认用左右翻页读岁月；保留「连续卷轴」作可选回退，不删数据  
3. **内容服务书感**：新事件优先能落成「可翻的一页」（有岁、有题、有短文），少堆无感权重噪音  
4. **插图跟页走**：已有高潮卡 / 死标图绑定到对应页，不另开全屏画廊抢戏  
5. **统计是生产工具**：盘点脚本进 `npm run`，规划与回归都用同一套数字  

### 2.3 明确不做

| 不做 | 原因 |
|------|------|
| 真·3D 书模 / 物理引擎翻页 | 成本高、移动端易卡；2.5D CSS/Canvas 翻页足够 |
| 多人共读云书架 / 账号云同步 | 规格外；本阶段本地一局一书 |
| 一次加 200+ 事件 | 质量与审计扛不住；本版硬门槛 +50 |
| 为书本重做全部文生图 | 复用 Phase 11 资产 |
| 重写模拟器核心调度 | 只改呈现层 + 事件数据 |

## 4. 验收指标

### 4.1 统计与内容

| 指标 | 目标 | 测法 |
|------|------|------|
| census 脚本 | 输出总数 / chain / importance / stage / tag Top | `npm run event-census` |
| 净增事件 | **≥50**（相对本版冻结基线 309 → **≥359**） | census diff |
| 新事件可玩 | 半自动可遇到 ≥15 条新 id（抽样 20 局） | 人工 + 可选 audit |
| 空气抉择 | 新事件不引入空气重大抉择 | `choice-audit` = 0 |
| 死因/门派 | 不回退 | death / sect 审计 |

### 4.2 书本交互

| 指标 | 目标 | 测法 |
|------|------|------|
| 封面 | 入世完成 → 本书封面（名/出身/立绘/种子） | 人工 |
| 翻页读一生 | 局中或结算可用左右翻页浏览日志页 | 人工桌面+窄屏 |
| 高潮插页 | importance≥4 或已绑定高潮图的页有明显插图位 | 人工 ≥8 局 |
| 封底 | 结算短传 + 死标图 + 立绘落在封底页 | 人工 |
| 回退 | 可切回「卷轴模式」不丢日志 | 人工 |
| 动效 | 翻页 1 套克制动画；不影响全自动推演性能 | 人工；auto 不卡死 |

### 4.3 样式

| 指标 | 目标 | 测法 |
|------|------|------|
| 一书气质 | 封面/内页/封底同一纸色与装订语言 | 对照 Phase 9 token |
| 触控 | 翻页热区 ≥44px；键盘 ←→ 可用 | 人工 |
| 不伤读 | 正文对比度与行长不差于现日志 | 对照第三版 |

## 6. 分柱细则

### 6.1 事件 census

输出至少包含：

- 总数、once / needsChoice 计数  
- 按 `chain` / `importance` / `stages` / 主 tag 分布  
- 与基线 309 的 diff（本版结束后 ≥359）  
- 可选：近 20 局触达率（后续增强，不阻塞 B0）

### 6.2 +50 模拟人生事件（题材配额）

> 气质：**烟火气 · 人情 · 体面与丢脸**，武侠皮、模拟人生骨。  
> 默认：`importance` 2～3 为主，少量 4；多数 `needsChoice`；尽量 `queueEvent` 轻因果，忌空抉择。

| 桶 | 建议条数 | 示例母题 |
|----|----------|----------|
| 邻里乡党 | 8 | 借粮、劝架、婚丧随礼、井边闲话 |
| 钱粮生计 | 8 | 涨租、折本、意外横财、赊账被催 |
| 节气岁时 | 6 | 端午、中秋、守岁、春荒 |
| 体面与闲章 | 6 | 被嘲出身、争座次、请帖、丢脸 |
| 家宅亲缘 | 6 | 父母期望、手足争执、远亲投靠 |
| 市井奇遇（轻） | 6 | 骗子、走失孩童、义助摊贩 |
| 修身琐事 | 5 | 失眠、戒酒、练字、养伤复健 |
| 江湖边缘烟火 | 5 | 客栈八卦、镖旗路过、山贼过境未战 |
| **合计** | **50** | 可 ±2 桶内调剂，总数 ≥50 |

**命名建议**：`life_*` / `slice_*`；`tags` 含 `日常` 或 `人情`；无门派终章抢戏。  
**链**：多数 `chain` 可空或 `civic` / `wanderer`；禁止误挂 `sect` 终章队列。

### 6.3 书本交互（产品规格）

```
封面 Cover
  · 姓名 / 性别 / 出身 / 立绘
  · 种子 · 模式
  · CTA：揭开这一生

内页 Spread（右页主文，左页可放岁数/插图）
  · 一页 ≈ 1～N 条同岁或同主题日志（分页算法可调）
  · 高潮页：大插图 + 短题 + 正文
  · 页脚：页码 · 「第 X 岁」

目录 Toc（可选 P1）
  · 按高潮 / 按阶段跳转

封底 Back
  · 死标图 · 精死因 · 短传 · 评分
  · 分享 / 重开 / 回顾目录
```

**翻页**

- 按钮：上一页 / 下一页  
- 手势：窄屏左右滑（P1）  
- 键盘：← →  
- 全自动推演中：书可停在「当前岁」书签页，不强制每条都翻（避免动画风暴）

**与现有回顾关系**

- 「回顾一生」卷轴可保留为高级选项  
- 默认结算进入 **封底 → 可向前翻回内页**

### 6.4 交互样式调整（收束在书壳内）

- 装订线、页边、纸纹与现有 `--paper / --ink / --cinnabar` 统一  
- 翻页阴影克制；禁止霓虹/玻璃拟态  
- 抉择仍用现有 choice-box，可视觉落在「书页夹条」上，不另造一套表单风

## 7. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 翻页导致全自动卡顿 | auto 模式降级为书签更新，无翻页动画 |
| 分页切碎因果关系 | 同事件正文+去向尽量同页；分页单测 |
| +50 事件稀释主线 | 低 importance + 权重上限；主链权重不降 |
| 新事件空气抉择 | 写入时对照 choice-audit 规则；B3 末必跑 |
| 窄屏书页难读 | 单页单栏优先；插图可折叠 |

回滚：Feature flag `lifeBookEnabled`（默认 true）；关则回卷轴 UI，事件数据可保留。
